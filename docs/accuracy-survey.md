# Accuracy Program — Phase 0 Survey (M0)

**Program:** the accuracy program (`GO accuracy` 2026-09-01) — [vision rev. 3](https://github.com/PyDevices/audiocomponents) companions live in the anchor repo's `docs/`.
**Method:** 12 family researchers (the `instrument-researcher` agent) hunting sources fresh; every gold grade, OSS license, and unverified license call re-checked by an adversarial audit agent that fetched the URLs itself; an M0 completeness critic over the assembled result. Every cited source was visited during the run; dead links are recorded as not-found, never as evidence.
**Gate:** this document is Phase 0's deliverable, presented for `APPROVE ACCURACY PHASE 0`.

## The headline numbers

| Grade | Count | Meaning |
|---|---|---|
| gold | 13 | a hardware-capture source reached, provenance and license read |
| literature | 34 | schematics / service manual / published models locatable and sufficient |

Coverage: **53 of 53** instruments surveyed.
