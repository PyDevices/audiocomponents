## 0. The finding that changes the grade

The task brief's risk was named correctly and it is confirmed: the TB-303 is
"enormously cloned," and both of the survey's two capture sources turn out to
fail gold for reasons that track that exact risk, plus a paywall each. Neither
failure was visible from the survey's own text; both required re-fetching the
pages this session.

1. **Loopmasters "Three Zero Three"** — re-fetched this session. Its own
   product description states the pack was multi-sampled from **"Stock 303,
   Borg Modified 303 and four more incredible hardware clones"** — six units,
   named as a group, with **no per-file or per-folder attribution** anywhere
   on the page saying which loops/hits/multisamples came from which unit.
   "Borg Modified" is a real, substantial performance modification (by
   Analogue Solutions, confirmed via `WebSearch` this session — comparable in
   scope to the better-known Devil Fish mod, adding control and circuit
   changes beyond stock). So even granting that one of the six source
   machines really is an unmodified TB-303, there is no way to know from this
   pack which specific samples are of *that* one rather than of the modified
   unit or the four unnamed clones. This is the clone/mod-contamination risk
   the task named, confirmed by the source's own wording, not inferred.
   Independently, and enough on its own: **the pack is paid** ($24.45 for
   Multi-Samples & Hits alone, up to $46.95; re-confirmed by fetching the
   pricing this session), with only a generic, unlabeled "taster pack"
   available for free — not purchased, per this pass's no-budget constraint.

2. **OXIDE Sound Lab (Bandcamp)** — re-fetched this session. The survey
   credited this pack with a "Creative Commons, no attribution required"
   license and cited it toward D3's known-settings credit ("3 documented
   filter positions"). Two things don't hold up on a fresh read: **the page's
   formal Bandcamp license field reads "all rights reserved"**; the
   Creative-Commons wording appears only in the informal about-blurb, and
   the two contradict each other on the same page (independently reconfirmed
   this session — the survey's own license-audit appendix had already caught
   this exact contradiction, `accuracy-survey.md:955`, and this session's
   fresh fetch agrees). And **the pack is not free**: it is Bandcamp
   pay-what-you-want with a stated **$3 USD minimum**, confirmed by fetching
   the pricing this session — a paywall under this pass's no-budget rule,
   independent of the license question. On top of both: the description says
   only "the vintage Roland TB-303," never asserting the unit was stock/
   unmodified — a real gap given how common mods and clones are (§3).

Both legs of the survey's gold call turn out to be paywalled; one is also
license-contradictory, and the other mixes a genuine stock unit with a named
modification and four unnamed clones with no way to isolate which is which.
Per this task's own standard ("a real, well-licensed capture of the wrong
machine is not gold"), a paywalled or attribution-blind capture of a
*possibly*-wrong machine is not gold either — dropped.

## 3. What the machine is, mechanically

Single-VCO analog subtractive monosynth: one oscillator, switchable
**sawtooth or square** wave (Wikipedia, "Roland TB-303," fetched this
session), through a **24 dB/octave low-pass resonant filter, non-self-
oscillating** (same source), with an envelope generator sweeping the filter
cutoff. Tim Stinchcombe's analysis (§1), read this session, derives the
filter as a 4-pole **diode ladder**, whose defining nonlinear behavior (diode
clipping shaping the resonance/self-oscillation character) is exactly the
kind of circuit-specific detail a plain biquad cannot reproduce — see §6.
Production run **1981–1984**; no source read this session (Wikipedia, the
service notes' description) states a hardware revision across that run,
unlike the electromechanical-piano family this program already found two
revisions for. The famous "acid" sound most listeners associate with the
name is not purely stock hardware, though: it is commonly produced by
external overdrive/distortion (mixer or pedal) or by well-known performance
modifications (Devil Fish, Borg — both confirmed real and distinct from
stock in sources fetched this session, §0/§1) rather than the unmodified
303's own circuit. DJ Mag's clone-usage piece (fetched this session,
https://djmag.com/longreads/8-best-tb-303-clones-according-artists-who-use-them)
states plainly that most working musicians in the acid-house scene today
use clones or modified units rather than stock originals — direct
corroboration, from a source outside the survey, of the exact contamination
risk this dossier's grade call turns on.

## 4. Hardware voice structure vs. the module

**Hardware:** strictly monophonic — Wikipedia's own spec table states
"Polyphony: monophonic" (fetched this session). One VCO, one voice, no
multitimbrality (the internal sequencer plays one line).

**Module:** `MAX_VOICES = 1  # Monosynth` (`tb303.py:62`), enforced by
`if len(voices) >= MAX_VOICES: steal_oldest()` (`tb303.py:78-79`) before
every note-on. **Matches exactly.** Per Brad's "if it was monophonic in real
life, it's monophonic here" rule, this is the module already doing the right
thing — no structural change indicated or proposed.

## 6. What the module would need if ever rebuilt — read, not measured

Read from `tb303.py` only; nothing below was rendered or listened to this
session, and no hardware capture exists to measure against yet.

- **No waveform switch.** Only `SAW = make_table(...)` is defined and used
  (`tb303.py:42,98`); the hardware's square-wave option (§3, §5-criterion-1)
  has no macro or code path. `MACRO_LABELS` currently uses 9 of 16 slots
  (`tb303.py:9-12`) — room exists for a `Waveform` toggle macro without
  hitting the contract's 16-macro ceiling (roadmap §3's free-to-add rule).
- **The filter is a generic biquad, not a diode-ladder model.** `lp =
  synthio.Biquad(synthio.FilterMode.LOW_PASS, cutoff, Q=res)`
  (`tb303.py:96`) is audioif's standard resonant low-pass — it has no
  nonlinear diode-clipping stage, which Stinchcombe's analysis (§1, §3)
  identifies as central to the filter's character, especially at high
  resonance. This is exactly the kind of gap the vision's toolkit expansion
  (§1: "a corrected and widened biquad," "a family of saturation curves")
  targets — a saturation stage in the filter's feedback path is the natural
  toolkit-level move, but no specific curve or parameter is sourced here;
  this is a direction, not a spec.
- **The Accent scaling constants (0.7, 1.2, 0.5 at `tb303.py:86-89`) are
  unsourced.** The *mechanism* (accent drives both envelope and VCA
  together) is corroborated by the service notes' block diagram; the exact
  numbers are a prior agent's plausible-sounding choice, not a cited
  measurement. Worth checking against Stinchcombe's or the service notes'
  circuit values directly if this instrument is ever rebuilt.
- **No slide/glide (portamento) between adjacent notes.** The 303's slide
  function — legato glide between two sequencer steps when the second note
  is flagged "slide" — is one of the sound's most identifiable features
  (part of what makes the "acid squelch"), and nothing in `handle_event`
  (`tb303.py:71-116`) implements a pitch ramp: every note-on presses a fresh
  voice at its target frequency immediately. This was found by reading the
  code this session, not sourced to a specific document beyond the general
  knowledge that slide is a documented sequencer feature on the real
  hardware (Wikipedia's TB-303 article describes the pattern-programming
  interface but was not checked this session for slide's exact wording) —
  flagged for whoever next revisits this module to source properly before
  acting on it.
- **The "Overdrive" macro doesn't distort.** `overdrive = 1.0 + value0*3.0`
  (`tb303.py:115`) is pure linear gain applied before a single multiply into
  `amp` (`tb303.py:89`) — `synthio.Note.amplitude` clamps at 1.0, so past a
  certain point this macro can only saturate the note's raw amplitude
  parameter, not actually waveshape the signal the way a real overdrive
  pedal or a Devil Fish mod would. Given §3/§5-criterion-4, this macro is
  reasonable to keep (macros are the instrument's character, not the
  contract — vision §2.2) but its current implementation doesn't do what its
  name promises; a `audiofilters`/saturation-curve stage (vision §1) is the
  toolkit-level fix if accuracy to the "driven" 303 sound is ever wanted,
  though the *stock* machine's own reference target (§3) has no overdrive at
  all — worth deciding explicitly which of the two this macro is for, rather
  than leaving it ambiguous.

## 7. MCU budget and macro budget

Per-voice cost is already minimal: one `synthio.Note`, one `Biquad` filter,
one one-shot `LFO` for the envelope-mod sweep, one `Math` node
(`tb303.py:93-98`) — no wavetable beyond the 39-harmonic `SAW` table, no
convolution, no `audioconvolve.FRAMES` latency to disclose. Nothing proposed
in §6 (a waveform macro, a saturation stage in the filter path) meaningfully
changes this: a second wavetable and a saturation curve are both cheap
relative to the toolkit additions already used elsewhere in this program
(e.g. `tr808`'s METAL-bank correction). **No `" - lean"` patch is expected**
on today's evidence — this instrument was already the cheapest structural
shape (monophonic, one voice) before any of §6's proposals.

`MACRO_LABELS` carries 9 of 16 slots (`tb303.py:9-12`) — seven free. A
`Waveform` macro (§6) is the one addition this dossier would actually
propose if this instrument is rebuilt; nothing else here requires a new
front-panel control.
