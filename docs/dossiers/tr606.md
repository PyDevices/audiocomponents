## 3. Hardware structure vs the module

**Seven nameable sounds, five real simultaneous circuits — two different
numbers, both confirmed this session, and the module already has the
first one right.** `NOTE_MAP` (`tr606.py:42-50`) lists exactly the seven
named sounds the hardware has (Bass Drum, Snare, Low Tom, Hi Tom, Closed
Hat, Open Hat, Cymbal) — unlike every sibling in this family surveyed so
far, nothing is missing here. But Wikipedia's infobox states "Polyphony:
7" (§1), while **two independent primary sources read this session say
5**: Polynominal's own spec table has a distinct "Polyphony : 5" field
next to "Percussions: 7" (not a typo — two separate rows), and the
service notes' own spec page lists the **"INSTRUMENT Mix Control"** as
six pots — Accent plus five *instrument* levels — because Low+High Tom
share one physical level control ("L.H. Tom") and Open+Closed Hi-Hat
share another ("O.C. Hihat"). 5 instrument channels, 7 named sounds:
Wikipedia's "7" is counting nameable sounds, the same
nameable-voices-vs-circuits conflation `tr909.md` §3 and `tr808.md` §3
already found in their own families' infoboxes. The primary sources,
read directly this session, are preferred: **5.**

**The schematic's block diagram (page 4, rendered and read this
session) shows exactly why**, per voice:

- **BD**: two independent oscillators, **OSC (IC15A)** and **OSC
  (IC15B)**, each with its own trim, summed at one shared **LEVEL** pot
  before the mixer. Own circuit; two-oscillator core.
- **SD**: one tone oscillator (**OSC IC10A**) plus one noise chain
  (**HPF Q32 → VCA Q30**, gated by **ENV Q16**/**ATTACK Q17**), summed
  at one shared **LEVEL** pot. Own circuit; matches the module's
  existing two-part design already.
- **LT/HT**: drawn inside **one enclosing box**. Each tom has its own
  **ATTACK** stage and its own oscillator (**IC9A** for LT, **IC9B**
  for HT) — but both oscillators feed into the **same ENV block
  (Q305,306)**, which drives the **same LPF → VCA (Q310)**, which feeds
  the **same LEVEL** pot. Only one tom's envelope/VCA can be active at a
  time: a genuine shared circuit, not merely a shared fader, and it
  matches the service notes' "L.H. Tom" combined mix control exactly.
- **CY**: two parallel chains, **BPF (IC15B) → VCA (Q39) → HPF (Q40)**
  and **BPF (C15A) → VCA (Q38) → HPF (IC12B)**, both gated by **ENV
  Q35**, summed at one shared **LEVEL** pot — matches Baratatronix's
  "high metal noise" / "low metal noise" description closely. Own
  circuit.
- **OH/CH**: both feed from the same six-oscillator **HD14584B** bank
  (confirmed genuine on the schematic's own IC-pinout page, §1) split
  into 7100 Hz/3440 Hz bands by bridged-T filters (Baratatronix). In the
  block diagram, **ENV Q36 (OH)** and **ENV Q31,C42 (CH)** both feed the
  **same VCA (Q37)**, the **same HPF (IC12A)**, and the **same LEVEL**
  pot — a directly-visible shared circuit, exactly as Baratatronix
  states. OH's envelope is additionally gated by an **"ENVELOPE SHUT
  OFF" (Q24,25)** block fed straight from **"TEMPO CLOCK"** — the
  schematic's own confirmation of Baratatronix's claim that **open
  hi-hat decay is not a manual control on real hardware; it tracks
  sequencer tempo.**

**Module today: `MAX_VOICES = 12`** (`tr606.py:102`), a pooled allocator
(`trigger_voice`/`steal_oldest`, `tr606.py:107-118`, calling
`_support.trigger_voice`/`_support.steal_oldest`,
`_support.py:252,237`) — more than double the reference's real 5-circuit
polyphony. Hi-Hat already chokes correctly (`open_hat_keys`,
`tr606.py:172-176,182-183`: closing the open hat releases it before the
new hit plays) — the one voice group the current code already gets
structurally right. **Tom does not**: Low Tom and High Tom
(`tr606.py:160-167`, the `elif pitch in (41, 43, 45, 47, 48, 50):`
branch) each get an independent key from `key_of(channel, note_id,
data0)` (`_support.py:194`, called at `tr606.py:128`) and so do **not**
choke each other in the current code — even though §3's schematic
reading shows they share one VCA on real hardware. This is the same bug
class `tr707.md`/`drumtraks.md` found in their own hi-hat handling,
found here in the toms instead, and backed by a direct block-diagram
reading rather than an inference from arithmetic alone.

**Proposed structural change**, justified entirely by the schematic
read this session: rebuild as **5 fixed circuit-groups holding 8
resident `synthio.Note`s** (§5), replacing the pooled 12-slot allocator.
This matches the hardware's real 5-way simultaneous polyphony exactly —
Brad's both-directions rule applied in the *reducing* direction, the
same way `tr909.md`/`tr707.md`/`sp1200.md` reduced or reconciled their
own`MAX_VOICES`/voice-cap mismatches.

## 4. Modeling approach, by voice group

- **Bass Drum** (`tr606.py:138-144`) — propose **2 resident Notes**
  where the module has 1 today: the schematic shows two independent
  oscillators (IC15A, IC15B) summed, not one SINE with a pitch drop.
  The specific frequency/level relationship between the two oscillators
  is **not stated** at the block-diagram level of detail this session
  reached (no component-value schematic page beyond the block diagram
  was read) — Station B's synthesis call, informed only by "two
  oscillators, summed," not by a measured ratio. Keep `bd_pitch`
  driving the primary oscillator; the second is new territory.
- **Snare Drum** (`tr606.py:147-157`) — keep the existing 2-Note
  tone+noise design; it already matches the schematic's OSC(IC10A) +
  HPF/VCA-noise structure well. No structural change proposed.
- **Tom** (`tr606.py:160-167`) — propose collapsing Low Tom and High Tom
  onto **one shared resident Note**, retuned per hit and choking the
  other, mirroring the Hi-Hat pattern the module already implements
  correctly (`tr606.py:170-183`) — directly justified by §3's shared
  ENV/LPF/VCA finding. The six note numbers currently routed to this
  branch (`41, 43, 45, 47, 48, 50`) stay as alternate GM triggers for
  the same two physical sounds; nothing about that routing needs to
  change.
- **Cymbal** (`tr606.py:186-193`) — keep the existing 2-Note structure;
  recommend re-anchoring the two filters at the literature-sourced fixed
  bands (≈7100 Hz high, ≈3440 Hz low, §3) instead of both deriving from
  one `cym_tone` variable scaled ×1/×1.5 (`tr606.py:189-190`) — the
  schematic's bridged-T split is a fixed design choice, not one knob
  scaling two filters together.
- **Hi-Hat** (`tr606.py:170-183`) — keep the existing 1-Note,
  already-choking design; it is the voice group this session's evidence
  corroborates most directly. Recommend re-centering its HPF near the
  same ≈7100 Hz band instead of tying it to the Cymbal knob
  (`cym_tone * 1.5`, `tr606.py:179`) — currently Hi-Hat brightness rides
  on the Cymbal macro, which the schematic gives no basis for. The
  `oh_decay` macro (`tr606.py:97,178,227`) is a **stated, deliberate
  divergence**: real hardware ties open-hat decay to sequencer tempo
  (§3), and no signal in the twelve-method instrument contract carries
  tempo into a component — a manual macro is the closest reachable
  approximation, not a claim of authenticity.

No convolution is proposed; no `audioconvolve.FRAMES` latency is
incurred. No `audiodynamics` need was identified — nothing read this
session describes a compression/limiting stage anywhere in this
machine's signal path; it is the simplest circuit found in this family
so far.

## 5. The FIXED-CIRCUIT map (mandatory)

Per the operating charter and the pattern `tr909.md`/`tr707.md`/
`sp1200.md`/`drumtraks.md` all used: every voice becomes a **permanent
set of `synthio.Note` objects, retriggered in place**, matching how the
hardware's own always-present analog circuits behave — nothing allocated
at strike time, nothing released mid-play. Every row is justified
directly from §3's schematic reading:

| Voice | Resident Notes | Justification |
|---|---|---|
| Bass Drum | 2 | two independent OSCs (IC15A, IC15B) summed at one LEVEL — schematic p.4 |
| Snare Drum | 2 (tone + noise) | OSC(IC10A) + HPF/VCA noise chain — schematic p.4 |
| Tom (Low+High, shared) | 1 (shared, retuned per hit, chokes) | independent OSCs share ENV(Q305,306)+LPF+VCA(Q310)+LEVEL — schematic p.4, corroborated by the service notes' "L.H. Tom" mix control |
| Cymbal | 2 (high-band + low-band) | two parallel BPF→VCA→HPF chains off the shared oscillator bank — schematic p.4, corroborated by Baratatronix |
| Hi-Hat (Open+Closed, shared) | 1 (shared, retuned per hit, chokes) | OH and CH share VCA(Q37)+HPF(IC12A) directly in the block diagram — corroborated by Baratatronix; already correctly modeled in today's code |
| **Total** | **8** | 5 below the 13-note ceiling — the lightest budget rebuilt in this family so far (`tr909`=12, `tr707`=13, `sp1200`=12, `drumtraks`=12) |

No stretch slot is proposed; 8 resident Notes across 5 groups already
lands exactly on the hardware's own 5-circuit polyphony (§3), which is a
stronger structural argument than spending the remaining headroom on
anything not found this session.

## 7. MCU budget and macro budget

**MCU:** 8 permanently resident `synthio.Note`s (§5) — the lightest
budget rebuilt in this family so far, replacing today's 12-slot pooled
allocator (`tr606.py:102`) with something both smaller and correctly
bounded to the hardware's real 5-circuit polyphony. **No `" - lean"`
patch is expected.**

**Macros: 16 today (already at the ceiling, `tr606.py:9-13`), and the
finding worth stating plainly: the real machine has almost none of what
those 16 macros represent.** The service notes' own control list (§1,
§3) names exactly one tone-shaping surface on the whole front panel: the
six-pot INSTRUMENT MIX section (Accent + five instrument levels). No
tune, decay, snappy, or tone pot is documented anywhere read this
session — Wikipedia's "The sounds cannot be edited" (§1) says the same
thing independently. Of today's 16 macros, only **six** trace to a real
panel control (`Level`, `Accent`, `BD Level`, `SD Level`, `Cym Level`,
`Hat Level`); the other ten are synthesis-calibration inventions with no
hardware counterpart. One real panel control is also missing entirely:
**Tom Level**, the "L.H. Tom" combined mix pot §3 found, has no macro at
all today.

Proposed: swap the least panel-grounded of the ten
(`Cym Tone`, macro 12 — §4 found the cymbal's noise-band split is a
fixed bridged-T design, not knob-adjustable) for the one missing real
control:

dropping `Cym Decay` next (§3/§4: the cymbal envelope reads as fixed by
